MITSYantra – Academic Dashboard
Active Development Major Project

MITSYantra is a comprehensive, web-based student management system built specifically for Madanapalle Institute of Technology & Science. It centralizes all academic, administrative, and placement-related activities into a single, unified platform — eliminating information silos and streamlining communication across the institution.

The system replaces fragmented manual processes with automated, role-aware workflows. Whether it's a student checking their timetable, a faculty member posting attendance, or an admin managing placement drives — MITSYantra delivers the right information to the right person at the right time.

🏗️ System Architecture

Built on the MVC (Model-View-Controller) pattern using Java Servlets as the controller layer, JSP for dynamic views, and Oracle Database as the persistent data store. The application is deployed on Apache Tomcat 9, serving both desktop and mobile users through a responsive web UI. Role-based access control (RBAC) ensures each user type (Student, Faculty, Admin) sees only their relevant dashboards and actions.

👥 Role-Based Dashboard System

🎓 Student

View timetable, attendance, grades, notifications, placement status

👩‍🏫 Faculty

Mark attendance, upload materials, post announcements, manage events

🛡️ Admin

Manage users, view reports, configure placement drives, oversee all data
